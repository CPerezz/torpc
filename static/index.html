Trust Wallet Setup

📱 Open in Trust Wallet

Manual Setup:

  1. Copy the RPC URL above
  2. Open Trust Wallet → Settings → Networks
  3. Tap "+" to add a custom network
  4. Enter:
    • Network Name: ToRPC Privacy Network
    • RPC URL: (paste the copied URL)
    • Chain ID: 1 (mainnet) or 1337 (dev)
    • Symbol: ETH
